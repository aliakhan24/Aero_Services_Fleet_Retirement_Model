Data & updating

All data is embedded in this file as JavaScript constants (CUSTOMERS, ROWS, LOOKUPS, DEFAULT_SCENARIOS, DEFAULT_DUTY, BENCH). To refresh the dashboard with a future workbook export:

  1. Export Scenario Schedule (per-unit rows: customer group, ESN, platform, sub platform, pole, duty cycle, plant mission, equipment status, customer segment, age in days, Elite hours, MyFleet hours).
  2. Export retirement analysis (unit-level retirement dates and years) to compare against the model output.
  3. Export Scenario Controls (useful life, maximum life hours, opening date, early cap override, ramp years, annual maximum, ramp capacities, as-of date, duty hours).
  4. Rebuild the compact form: customers joined by a pipe character; each row as customerIdx,ESN,7-character base-36 code string (platform, sub platform, pole, duty, mission, status, segment),ageDays,eliteHours,myFleetHours, rows joined by semicolons. Keep ESN as text, leave unavailable values empty, and keep 0 as a real zero.
  5. Replace the constants, update the as-of date and BENCH values (or ignore the benchmark panel; it reports Custom assumptions when inputs differ from defaults), then confirm all integrity checks pass.

Age and hours values must be refreshed to the same date as the as-of date. Assumption sets can be exported and imported as JSON; no browser storage is used.

Offline use: Chart.js and the Inter font load from a CDN; for fully offline use, download chart.umd.min.js (Chart.js 4.4.1) next to this file and change the script src to it. All fleet data (1,792 records), calculations and tables work without network access, and charts display a fallback message if the library is unavailable.
